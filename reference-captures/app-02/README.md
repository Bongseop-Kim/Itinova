# 트리플 여행 일정 레퍼런스

수집일: 2026-09-04  
대상: 트리플 Android (한국어)

## 핵심 관찰

트리플은 `도시 → 날짜 → 동행/여행 성향 → 일차별 장소`를 빠르게 연결하고, 여행 중 필요한 예약·장소 탐색·동선 편집을 같은 일정 화면에 넣는다. 국내와 해외 도시는 처음부터 병렬 진입으로 제공한다.

## 현재 확인된 핵심 구조

`전역 홈(예약·AI·일정 생성)` → `여행 홈(도시 가이드·예약 탐색)` / `여행 보드(지도·일차 타임라인·예약/체크리스트/가계부)` → `장소 추가(지도/필터/개인 저장)` → `일정 편집(순서·거리·완료)` → `장소 상세/인라인 액션`

AI 추천은 `도시 → 기간 → 동행(복수) → 여행 스타일(복수) → 일정 밀도`의 5단계다. 공동 일정은 최대 15명까지 카카오톡·링크·외부 앱으로 초대할 수 있으나, 이 작업에서는 초대·링크 복사를 실행하지 않았다.

샘플로 `부산 여행`(2026.9.9–9.11)을 만들고 day 1에 부산역·광안리 해수욕장을 넣었다. 알림은 허용하지 않았고, 예약·결제·외부 공유는 실행하지 않았다.
