### 제품 결론

1. Itinova의 최소 생성 흐름은 `목적지 → 날짜 → 장소 1개 이상 → 일정`이면 충분하다. 선호도·동행·위치 추적은 모두 나중에 설정 가능하게 둔다.
2. 일정 화면은 날짜가 확정된 뒤에만 시간·동선·이동시간을 계산한다. 날짜 미정 상태는 별도의 초안으로 취급한다.
3. 하나의 여행 페이지에는 일정 외에도 지도, 장소 보관함, 예약/첨부, 메모, 동행 공유가 모인다. 이 다섯 영역이 국내·해외 공통 코어다.
4. 위치 추적, 공유, 예약 전달, Pro 체험은 초기 생성의 필수 단계가 아니어야 한다. Wanderlog도 모두 `나중에` 또는 건너뛰기를 제공한다.
